From a messy SSD to living art.

Seven milestones, one guided pipeline. The catalog is the system of record; everything downstream trusts it.

01 · Catalog

Non-destructive consolidation

Ingests local folders and NAS sources (HEIC, JPEG, PNG, WebP, TIFF), detects exact and perceptual duplicates with best-original recovery, and consolidates into a single content-addressed store — sources left untouched until you approve archival.

SHA-256 · journaled
02 · Analyze

Offline, deterministic analysis

A provider-neutral engine scores technical and aesthetic quality, saliency and subjects, crop safety, color story, and pairing affinity — every signal CPU-computable and reproducible, no cloud required.

air-gapped
03 · Direct

Art-direction proposals

A deterministic policy engine suggests treatments — full-bleed, contain-and-matte, panoramic, square, or diptych — each with an explicit rationale, captured in a versioned ArtDirectionManifest.

explainable
04 · Render

Deterministic renderer + validator

One manifest renders byte-identical output at 1080p, 4K, or any exact size in sRGB. A validator gates publishability: dimensions, profile, hash, region math, no unintended cropping. Upscaling is never silent.

verified
05 · Approve

Approval & history

Per-image approve, reject, undo, redo, and batch — with append-only history and rationale. A Darkroom Bench web UI makes the whole loop usable in a browser, keyboard- and screen-reader-first.

WCAG AA
06 · Publish

Safe destination adapters

Filesystem, simulator, Samsung Art Mode (canary upload, exact-ID replace, rollback) and Home Assistant coordination with an exclusive write lease. A durable watcher ingests new photos exactly once.

leased · journaled
07 · Personalize

Taste Lens

Versioned, isolated preference profiles rerank candidates with explainable deltas, tuned by active-learning pairwise comparisons. Disable it and you get the exact baseline back. Approved output never changes.

What it does.

The full surface, end to end.

Catalog

Content-addressed store

SHA-256 identities keep duplicate references from creating duplicate work. Connector-scoped source identity means renames, moves, and remote revisions never collide.

Analysis engine

Deterministic signals, no cloud

Perceptual embeddings, technical and aesthetic quality, subject saliency, per-direction crop safety, color story, and pairing affinity — all computed offline on CPU and reproducible run-to-run.

  • Exact + perceptual near-duplicate detection with best-original recovery
  • RAW and corrupt files report explicit status instead of vanishing
  • Provider boundary open to local, cloud, or hybrid backends later
Art direction

Treatments with rationale

Policy engine proposes full-bleed, matte, panoramic, square, or diptych, each with evidence. Explicit target overrides win. The manifest is the single source of truth for rendering.

Render & validate

Exact, verified output

Byte-deterministic 1080p / 4K / custom sRGB from one manifest, gated by a validator that rejects wrong dimension, profile, hash, or unintended crop.

Web & headless

Control from anywhere

A dependency-light Darkroom Bench web UI plus a headless CLI with stable exit codes and JSON output — perfect for launchd, cron, or scripting.

Automation

Watcher, collections, rotation

A durable watcher ingests stabilized photos once. Collections and playlists rotate deterministically with intervals, shuffle-without-repeats, favorites, seasons, and show-now.

Operations

Production-ready plumbing

A crash-safe job orchestrator with classified outcomes, packaging for macOS launchd and Docker, and a migration tool that imports a legacy Samsung SSD non-destructively.

Private by construction.

Your originals, approvals, and TV credentials stay on your machine. Nothing leaves unless you explicitly turn it on and say exactly what will go.

DEFAULT POSTUREAir-gapped. No mandatory network calls during ingest, analysis, proposal, render, or local publish.
CLOUD IF OPTED INA plain-language disclosure lists exactly what leaves — downscaled derivatives and selected metadata only, never originals, secrets, or TV credentials.
EXCLUSIONSPer-source and per-image exclusions for full resolution, faces, GPS, and named folders, enforced before anything is sent.

Taste Lens.

After the baseline is trustworthy, add personalization without eroding it.

Isolation first

Ranking that is reversible and explainable

Versioned profiles rerank candidates as a deterministic “baseline + personal delta,” each contribution explained. Disable Taste Lens and ranking returns exactly to baseline. Approved output always renders identically.

Learn

Pairwise active learning

Informative pairs are chosen for sample efficiency; every lift against baseline is measured and gated before it is promoted.

Discover

An adaptive Taste Deck

A federated creator catalog with artist spotlights, a likely / adjacent / wildcard feed, and a Familiar ↔ Surprising dial. Calibrated and isolated.
